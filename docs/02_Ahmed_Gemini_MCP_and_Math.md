## A5 | Optional exact optimizer, 04:15–05:00 if core gates pass

This is the guidebook's Weighted Set Cover feature. It fits Gmail-only onboarding when presented as a what-if: “Which of my known plans would preserve every listed feature at the lowest monthly cost?” No personal budget or questionnaire is required.

1. Use a small verified plan-to-feature catalog and map only confident plan matches. For this exercise all known features of those plans form the required set. Compute independently for each currency. If an active plan's features or price are unknown, disclose missing coverage and withhold a full-portfolio saving.
2. Enumerate all subsets for a small catalog. For n plans there are 2^n subsets. Keep a subset if the union of its features covers the required set and it includes every protected plan. Select the minimum summed monthly cost, breaking ties by fewer removals then stable plan IDs. Report the retained features, candidate removals and conditional monthly reduction. Expose this as an additional MCP tool only after its tests pass.
3. Unit test with fictional plans A = PKR 3,000 for coding + writing, B = PKR 2,000 for writing, C = PKR 1,500 for design, D = PKR 2,500 for coding. Current cost is 9,000. Across 16 subsets, A+C covers all three features for 4,500. Add a unique IDE feature to D and the minimum becomes B+C+D for 6,000. These are separate optimizer fixtures from the Gmail billing demo. Gmail receipts establish purchase evidence; the catalog establishes modeled features. Report the output as conditional on those assumptions.
